# 🎮 PlayStation Console UI Launcher for PC

A modern, immersive, and sleek desktop interface designed to transform your PC into a full-screen PlayStation console experience. Say goodbye to standard desktop clutter and navigate your library, media, and games using your controller—bringing the true living-room console experience directly to your computer.

---

## ✨ Key Features

* **Authentic Console Interface:** Converts your Windows desktop into a fluid, full-screen dashboard inspired by PlayStation's clean aesthetic.
* **Full Gamepad Navigation:** Native controller support designed for seamless, effortless navigation without ever needing a mouse or keyboard.
* **Unified Game Launcher:** Organize and launch your favorite titles across multiple platforms (Steam, Epic Games, GOG, or standalone games) from a single centralized hub.
* **Fluid Animations & Audio:** Smooth UI transitions, ambient soundscapes, and crisp visual effects engineered for an authentic gaming environment.
* **TV & Couch-Gaming Ready:** Optimized for high-resolution displays, big screens, and home theater PC (HTPC) setups.

---

## 🎯 Target Audience

- **Living Room Gamers:** Ideal for users connecting their PC to a TV for a hassle-free, couch-gaming setup.
- **Console Enthusiasts:** Anyone who loves the PlayStation user experience and wants to recreate it on their PC.
- **Minimalist Setups:** Gamers looking for a dedicated, distraction-free gaming environment without desktop pop-ups and icons.

---

## 🛠️ Getting Started

### Prerequisites
- Windows 10 / 11
- A connected gamepad (Xbox, DualShock, DualSense, or generic XInput controller)

### Quick Start
1. Download the latest release from the **Releases** tab.
2. Extract the files and launch the executable.
3. Configure your game library and enjoy the console experience!
